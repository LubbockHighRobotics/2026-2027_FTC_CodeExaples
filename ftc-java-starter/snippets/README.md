# Snippets

**These are fragments, not OpModes.** They will not build on their own and they
won't appear on the Driver Station. Copy the piece you need into a file you
already have.

| File | What it fixes |
|---|---|
| `mecanum-mix.java` | Turning three stick inputs into four wheel powers |
| `imu-init.java` | IMU setup, and how to work out your hub orientation |
| `angle-wrap.java` | 179° to −179° being 2°, not 358° |
| `bulk-caching.java` | A slow loop caused by reading the same sensor repeatedly |
| `gamepad-rising-edge.java` | A button press registering 50 times instead of once |
| `slew-rate-limit.java` | A drivetrain that jerks when the driver snaps the stick |
| `ticks-per-unit.md` | Working out ticks per inch for your robot |
